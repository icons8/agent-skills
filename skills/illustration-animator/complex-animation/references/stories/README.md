# Story catalog

What Icons8 animators actually did with each illustration: one entry per animation, written from its storyboard and the measured motion. Use it as a library of solutions: before inventing a story for a new illustration, find entries with the same objects or situation (search by words from the file name) and see what moved and how.

One file per style. Entry format:

```
## <name>
Objects: what is in the picture.
Story: what happens, in order.
Shape: cycle or vignette · loop length · what is the peak · what the symbols do.
```

The descriptions are made from 8–16 frames of each animation. Checked: 20 random entries by hand and every entry with a quick event (jump, toss, turn) on 16 frames; the remaining risk is short events misread from a storyboard. If an entry contradicts the drawing, trust the drawing; corrections go straight into the entry.

The analyze step uses the catalog in step B¾ (SKILL.md).
