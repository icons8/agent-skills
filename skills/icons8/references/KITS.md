# Kits

Ready concept lists so you do not invent the icon set for every screen. Start from the kit,
delete what the screen does not need, add what is missing.

Ids are **Material Outlined (`m_outlined`)**, verified in July 2026. For any other pack, run the
same `query` with your `platform` and keep the `commonName` column as the target: it matches in
most packs, and where it does not you will see it immediately.

`✓` means rendered and checked at 48px.

Queries only: ids depend on the pack. Run each with `platform="color"` (or `plumpy`,
`pulsar-color`, `dusk`) at 48-128px.

`rocket` → `rocket` · `idea` → `idea` (lightbulb) · `puzzle` → `puzzle` · `gift` → `gift` ·
`crown` → `crown` · `lightning` → `lightning-bolt` · `cloud` → `cloud` · `trophy` → `trophy` ·
`badge` → `badge` · `group` → `groups` · `company` → `organization` · `survey` → `survey` ·
`workflow` → `workflow` · `globe` → `globe`

For a hero above 200px an illustration usually beats a scaled-up icon. Ouch! (ouch.pics) is the
in-house illustration set and is not part of this MCP.
